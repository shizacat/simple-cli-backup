# Simple CLI Backup

Простая настройка бэкапов на северах.

Возможности:
- Настройка через yml файл
- Для запуска используется одна точка входа
 	В cron можно указать один файл, а все рассписание будет в файлах настроек

## Требования 

Python 3.10+

## Разработка

### Локализация

```bash
cd ./
pygettext -a -d scb source/
```
