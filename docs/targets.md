# Цели

Цель (target) — источник данных одного бэкапа внутри среза. Срез перечисляет цели в поле `target`. Для каждой цели он создает отдельный временный каталог и передает его в `process`. Цель возвращает пути файлов, которые нужно положить в архив: готовый список или итератор. Сама цель архив не собирает.

Срез упаковывает файлы всех своих целей в один архив. Тип архива выбирает срез, сейчас это `tar.gz`. Готовый архив отдается местам из поля `place`. Куда копировать результат и как его ротировать, цель не решает.

## Контракт

Класс цели лежит в пакете `sback/targets` и наследует `TargetBase` из `sback/lib/target_base.py`.

- `name` совпадает с полем `type` в настройках.
- `description` краткое описание, показывается в списке плагинов.
- `config_model` — pydantic-модель поля `config`. Настройки цели.
- `process(tmp_dir)` пользуется временным каталогом и возвращает пути для архива. Файлы, созданные внутри `tmp_dir`, нужно отдать до выхода из `process`: после этого каталог удаляется.

Имя архива среза собирается через `archive_base_name`: `{имя}_{год}.{месяц}.{день}.tar.gz`, без индекса. Индекс добавляет место хранения, когда сохраняет этот архив.

Если тип из настроек не зарегистрирован или `config` не проходит `config_model`, возникает `TargetError`.

## Сейчас реализовано

`file` отдает существующие файлы и каталоги из `config.path`. Пути, которых нет на диске, пропускаются. Временный каталог ей не нужен: файлы уже лежат на месте.

```yaml
target:
  - name: files
    type: file
    config:
      path:
        - /etc
```

`mongodb` снимает дамп через `mongodump --archive --gzip`. На сервере должна быть команда `mongodump`. Поле `database` — шаблон имени: `*` означает все базы и стоит по умолчанию. Каждая подходящая база становится файлом `{база}.archive.gz`, а срез упаковывает эти файлы в свой архив.

```yaml
target:
  - name: mongo
    type: mongodb
    config:
      uri: mongodb://backup:secret@localhost:27017
      database: app_*
```

`mysql` пишет SQL-дамп через `mysql-connector-python`, без `mysqldump`. Цель сама открывает подключение, читает базу данных и собирает файл дампа.

Поле `database` — шаблон имени: `*` означает все пользовательские базы и стоит по умолчанию. `information_schema`, `performance_schema`, `mysql` и `sys` при `*` пропускаются. Для каждой подходящей базы цель делает `SHOW FULL TABLES` и оставляет только `BASE TABLE`. Представления, процедуры, триггеры и события в дамп не входят.

Для каждой таблицы цель берет `SHOW CREATE TABLE` и `SELECT *`. В `{база}.sql` попадают `SET NAMES`, отключение `FOREIGN_KEY_CHECKS`, `DROP TABLE`, оператор `CREATE`, который вернул сервер, и `INSERT` со значениями строк. Пустая таблица остается только со структурой. Срез упаковывает эти файлы в свой архив.

Флаг `mysqldump: true` переключает запись файла на утилиту `mysqldump`. Список баз цель по-прежнему читает коннектором, а `{база}.sql` пишет утилита с `--single-transaction`, `--routines`, `--triggers` и `--events`. По умолчанию флаг выключен, и утилита не вызывается.

```yaml
target:
  - name: db
    type: mysql
    config:
      host: localhost
      user: backup
      password: secret
      database: app_*
      mysqldump: true
```
