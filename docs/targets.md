# Цели

Цель (target) — источник данных одного бэкапа внутри среза. Срез перечисляет цели в поле `target`. Каждая цель готовит один файл: дамп, архив каталогов или результат команды. Срез не хранит эти файлы по отдельности. Он складывает их в один архив и отдает этот архив местам из поля `place`.

Цель не выбирает, куда копировать результат, и не делает ротацию. Это работа места хранения. Цель только готовит содержимое.

## Контракт

Класс цели лежит в пакете `sback/targets` и наследует `TargetBase` из `sback/lib/target_base.py`.

- `name` совпадает с полем `type` в настройках.
- `description` краткое описание, показывается в списке плагинов.
- `config_model` — pydantic-модель поля `config`. Настройки цели.
- `process(tmp_dir, dir_result)` создает итоговый файл в `dir_result` и возвращает его имя, не полный путь. `tmp_dir` можно использовать для промежуточных файлов.

Имя файла цели собирается через `archive_base_name`: `{имя}_{год}.{месяц}.{день}.{расширение}`, без индекса. Индекс добавляется позже, когда место хранения сохраняет уже общий архив среза.

Если тип из настроек не зарегистрирован или `config` не проходит `config_model`, возникает `TargetError`.

## Сейчас реализовано

`file` упаковывает файлы и каталоги из `config.path` в `tar.gz`. Пути, которых нет на диске, пропускаются. Имя архива: `{name}_{год}.{месяц}.{день}.tar.gz`.

```yaml
target:
  - name: files
    type: file
    config:
      path:
        - /etc
```
